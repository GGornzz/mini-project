# Mini Project - To-Do List

## Description

This project is a small full-stack To-Do List web application.

It was developed using Node.js, Express.js, HTML, CSS, and JavaScript.

The application provides a REST API with full CRUD operations.

## Technologies

- Node.js
- Express.js
- HTML
- CSS
- JavaScript
- Fetch API
